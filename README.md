# Praktikum React JS Dasar

## Cara menjalankan
1. Pastikan Node.js LTS sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat Local yang ditampilkan terminal.

## Fitur
- Profil mahasiswa memakai variabel dan komponen.
- Daftar empat mata kuliah memakai props dan key stabil.
- Penghitung kehadiran dengan batas 0 sampai 30.
- Daftar tugas: tambah, validasi input, tandai selesai, batalkan, hapus, dan filter Semua/Aktif/Selesai.
